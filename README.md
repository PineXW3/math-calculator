# Python Math Calculator
A simple command-line calculator built in Python. The main purpose of building this project is for me understand the fundamentals of Python.

## Features
* Basic arithmetic operations
    * Addition
    * Subtraction
    * Multiplication
    * Division

## What I Learned
* Loops and control flow
* String manipulation and input handling
* Type casting
* Functions, parameters, and arguments

## Future Improvements
Planned features for next version:
* Error handling for invalid input
* Support for multiple operations in a single line
* Exponentiation and root operations
